# OpenRouter Audio API Guide

This document explains how to use OpenRouter's audio output capabilities for text-to-speech via the Chat Completions API.

## Overview

OpenRouter provides access to OpenAI's audio models through the standard Chat Completions API. Audio output is generated by models like `openai/gpt-audio-mini` and `openai/gpt-4o-audio-preview`.

## Key Requirements

### 1. Streaming is Required

Audio output **requires** `stream: true`. Non-streaming requests will fail with:

```
Audio output requires stream: true
```

### 2. PCM16 Format Only (for Streaming)

When streaming, only `pcm16` format is supported. Other formats (wav, mp3, opus, flac) will fail with:

```
Unsupported value: 'audio.format' does not support 'wav' when stream=true. Supported values are: 'pcm16'.
```

### 3. PCM16 Audio Specifications

The PCM16 audio returned has these characteristics:
- **Sample Rate:** 24,000 Hz
- **Channels:** 1 (mono)
- **Bit Depth:** 16-bit signed integers
- **Encoding:** Little-endian

## Request Format

```javascript
POST https://openrouter.ai/api/v1/chat/completions

{
  "model": "openai/gpt-audio-mini",
```

## Streaming Response Format

The response is Server-Sent Events (SSE) with JSON chunks:

```
data: {"id":"...","choices":[{"index":0,"delta":{"audio":{"id":"audio_123"}}}]}
data: {"id":"...","choices":[{"index":0,"delta":{"audio":{"data":"BASE64_CHUNK"}}}]}
data: {"id":"...","choices":[{"index":0,"delta":{"audio":{"data":"BASE64_CHUNK"}}}]}
data: {"id":"...","choices":[{"index":0,"delta":{"audio":{"transcript":"Hello"}}}]}
data: {"id":"...","usage":{"prompt_tokens":10,"completion_tokens":50}}
data: [DONE]
```

### Delta Fields

- `audio.id` - Unique identifier for the audio (sent once at start)
- `audio.data` - Base64-encoded PCM16 audio chunks (sent multiple times)
- `audio.transcript` - Text transcript of the generated speech (sent in chunks)

### Usage Information

The final chunk before `[DONE]` includes token usage:

```javascript
{
  "usage": {
    "prompt_tokens": 10,
    "completion_tokens": 50,
    "total_tokens": 60,
    "completion_tokens_details": {
      "audio_tokens": 45
    }
  }
}
```

## Converting PCM16 to WAV

PCM16 is raw audio data. To play it in a browser, convert to WAV by adding a 44-byte header:

```javascript
function pcm16ToWav(pcmBase64) {
  const pcmBytes = Uint8Array.from(atob(pcmBase64), c => c.charCodeAt(0));

  const header = new ArrayBuffer(44);
  const view = new DataView(header);

  const sampleRate = 24000;
  const channels = 1;
  const bitsPerSample = 16;
  const byteRate = sampleRate * channels * (bitsPerSample / 8);
  const blockAlign = channels * (bitsPerSample / 8);

  // RIFF header
  writeString(view, 0, 'RIFF');
  view.setUint32(4, 36 + pcmBytes.length, true);
  writeString(view, 8, 'WAVE');

  // fmt chunk
  writeString(view, 12, 'fmt ');
  view.setUint32(16, 16, true);           // Chunk size
  view.setUint16(20, 1, true);            // Audio format (PCM)
  view.setUint16(22, channels, true);
  view.setUint32(24, sampleRate, true);
  view.setUint32(28, byteRate, true);
  view.setUint16(32, blockAlign, true);
  view.setUint16(34, bitsPerSample, true);

  // data chunk
  writeString(view, 36, 'data');
  view.setUint32(40, pcmBytes.length, true);

  // Combine header + PCM data
  const wavBytes = new Uint8Array(44 + pcmBytes.length);
  wavBytes.set(new Uint8Array(header), 0);
  wavBytes.set(pcmBytes, 44);

  return wavBytes;
}

function writeString(view, offset, str) {
  for (let i = 0; i < str.length; i++) {
    view.setUint8(offset + i, str.charCodeAt(i));
  }
}
```

## Complete Example (JavaScript)

```javascript
async function textToSpeech(apiKey, text, voice = 'alloy') {
  const response = await fetch('https://openrouter.ai/api/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${apiKey}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      model: 'openai/gpt-audio-mini',
      modalities: ['text', 'audio'],
      stream: true,
      audio: { voice, format: 'pcm16' },
      messages: [{ role: 'user', content: text }],
    }),
  });

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  const audioChunks = [];
  let buffer = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n');
    buffer = lines.pop();

    for (const line of lines) {
      if (!line.trim() || line === 'data: [DONE]') continue;
      if (line.startsWith('data: ')) {
        try {
          const chunk = JSON.parse(line.slice(6));
          const audioData = chunk.choices?.[0]?.delta?.audio?.data;
          if (audioData) audioChunks.push(audioData);
        } catch {}
      }
    }
  }

  // Combine all chunks and convert to WAV
  const pcmBase64 = audioChunks.join('');
  const wavBytes = pcm16ToWav(pcmBase64);

  // Create playable blob
  const blob = new Blob([wavBytes], { type: 'audio/wav' });
  return URL.createObjectURL(blob);
}

// Usage
const audioUrl = await textToSpeech('sk-or-...', 'Hello world!');
const audio = new Audio(audioUrl);
audio.play();
```

## Error Handling

OpenRouter wraps provider errors. Extract the actual message:

```javascript
if (!response.ok) {
  const error = await response.json();
  const rawError = error.error?.metadata?.raw;
  if (rawError) {
    const parsed = JSON.parse(rawError);
    console.error(parsed.error.message);
  }
}
```

## Limitations

1. **Streaming required** - No non-streaming audio output
2. **PCM16 only** - Must convert to WAV/MP3 client-side
3. **No direct TTS endpoint** - Must use Chat Completions API with modalities
4. **Text input only** - Audio input not supported through OpenRouter (as of this writing)
